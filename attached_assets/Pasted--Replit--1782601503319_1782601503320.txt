# Техническое Задание

## «Умный дом Яндекс» — Панель управления v3.0

**Платформа:** Replit  
**Дата:** 28.06.2026  
**Версия:** 1.0

## 1. Общие сведения

### 1.1. Наименование
«Умный дом Яндекс» — веб-панель управления устройствами умного дома с инженерным и пользовательским интерфейсами.

### 1.2. Назначение
Удалённое управление всеми устройствами умного дома Яндекс через единый веб-интерфейс с возможностью просмотра данных с датчиков, запуска сценариев и кастомизации отображения.

### 1.3. Режимы работы
- **Инженерная панель** — полный доступ ко всем устройствам, отладка, сценарии
- **Пользовательская панель** — адаптивный дашборд для планшета/телефона с виджетами

---

## 2. Технический стек

| Уровень | Технология |
|---------|------------|
| Сервер | Node.js + Express (прокси для обхода CORS) |
| Клиент | Vanilla JS (ES6+) |
| Стили | CSS3 (Grid, Flexbox, Custom Properties, clamp()) |
| Сборка | Python 3.x (генерация файлов из модулей) |
| Хранение | localStorage (конфигурация, кэш погоды, история) |
| Погода | Open-Meteo API (бесплатный, без ключа) |
| Геокодинг | Nominatim/OpenStreetMap (опционально) |

### 3.2. Схема взаимодействия

```
Браузер → Прокси-сервер (Node.js:3000) → Яндекс API (api.iot.yandex.net)
                                       → Open-Meteo (погода)
```

### 3.3. Принцип генерации
Проект собирается Python-скриптами. Каждый модуль генерирует определённый файл. Оркестратор `install.py` запускает все 14 модулей последовательно. Это позволяет:
- Версионировать конфигурацию
- Быстро вносить изменения в любой компонент
- Автоматизировать развёртывание

## 4. Функциональные требования

### 4.1. Инженерная панель (`/`)

| Функция | Описание |
|---------|----------|
| Авторизация | Ввод OAuth токена Яндекс |
| Объекты | Список households с кнопкой перехода к пользовательской панели |
| Комнаты | Группировка устройств по комнатам |
| Устройства | Карточки с названием, статусом (ON/OFF), элементами управления |
| Управление | Вкл/выкл (toggle), яркость (range), температура, цвет |
| Датчики | Отображение температуры, влажности, PM2.5, освещённости, батареи |
| Сценарии | Запуск сценариев умного дома |
| Поиск | Фильтрация устройств по названию |
| Активные | Сводка всех включенных устройств |

### 4.2. Пользовательская панель (`/panel`)

#### 4.2.1. Шапка и погода
- Карточка погоды на всю ширину (фиксированная)
- Температура, иконка погоды, описание, город, дата, время
- Влажность, вероятность осадков
- Индикатор статуса подключения (зелёная/красная точка)

#### 4.2.2. Навигация по комнатам
- Горизонтальные вкладки (как в браузере)
- Активная вкладка выделена цветом и увеличенным шрифтом
- Стрелки влево/вправо для переключения
- Drag-and-drop для изменения порядка вкладок
- Скролл с автопрокруткой к активной вкладке

#### 4.2.3. Плитки устройств
- **Адаптивная сетка**: 2 колонки (телефон), 3 (планшет), 4-5 (десктоп)
- **Размеры**: 1x1, 2x1, 1x2, 2x2 — изменение в режиме редактирования
- **Контент адаптивный**: шрифты и отступы меняются через CSS `clamp()` и классы `.tile-2x2`, `.tile-2x`
- **Цветовая индикация**: зелёная рамка = включено, без рамки = выключено
- **Управление**: клик по плитке переключает устройство
- **Слайдеры**: для диммеров (яркость) и штор (открытие) — работают внутри плитки
- **Датчики**: температура (красный), влажность (синий), PM2.5, батарея — в одну строку
- **Мини-графики**: SVG-спарклайн за последние 8 часов для температуры и влажности

#### 4.2.4. Режим редактирования (Edit Tiles)
- Кнопка ✎ в футере
- В режиме редактирования:
  - Появление крестика (удалить) и кнопки булавки (закрепить)
  - Кнопки размера (1x1, 2x1, 1x2, 2x2) в углу плитки
  - **Свободное перетаскивание** (drag-and-drop как на iOS): плитки меняются местами
  - Кнопка «+» для добавления скрытых плиток
  - Вкладки комнат можно перетаскивать
- Удаление с подтверждением
- Закреплённые плитки всегда сверху (жёлтая рамка)

#### 4.2.5. Конфигурация
- Все настройки сохраняются в localStorage
- Миграция со старых версий конфигурации
- Токен сохраняется автоматически
- Передача токена через URL при первом входе

## 5. Реестр типов устройств (TileTemplates)

Каждый тип устройства описан в `tile-templates.js`:

```javascript
'devices.types.light': {
  icon: '💡',
  label: 'Освещение',
  colorByStatus: true,        // зелёная рамка при включении
  clickAction: 'toggle',      // клик переключает
  defaultSize: { w: 1, h: 1 },
  allowedSizes: ['1x1', '2x1', '1x2', '2x2'],
  controls: [
    { type: 'on_off', instance: 'on', display: 'color' }
  ],
  properties: [],
  chart: false
}
```

Поддерживаемые типы: light, light.dimmable, switch, socket, thermostat, thermostat.ac, sensor.climate, sensor.open, sensor.presence, purifier, humidifier, curtain, remote.ir, vacuum_cleaner, cooking, kettle, washing_machine, dishwasher.

## 6. API и интеграции

### 6.1. Яндекс Умный дом

| Метод | Эндпоинт | Назначение |
|-------|----------|------------|
| GET | `/v1.0/user/info` | Все устройства, комнаты, группы |
| POST | `/v1.0/devices/:id/actions` | Управление устройством |
| GET | `/v1.0/scenarios` | Список сценариев |
| POST | `/v1.0/scenarios/:id/actions` | Запуск сценария |

### 6.2. Open-Meteo (погода)
- Бесплатный, без ключа
- Координаты по умолчанию: Москва (55.7558, 37.6173)
- Обновление каждые 30 минут
- Автоопределение города через Nominatim

## 7. Требования к интерфейсу (iOS-стиль)

### 7.1. Визуальные принципы
- Тёмная тема (фон #0f0f23, карточки #1a1a2e)
- Скруглённые углы (clamp(8px, 1.5vw, 12px))
- Адаптивные отступы и шрифты через CSS clamp()
- Плавные анимации (transition 0.3s)
- Цветовая индикация статуса (зелёный = on)
- Отсутствие лишних элементов (названия комнат убраны из плиток)
- Минималистичные иконки (эмодзи)

### 7.2. Взаимодействие
- **Клик** — переключение устройства
- **Долгое нажатие** (в режиме редактирования) — удаление
- **Перетаскивание** — свободное перемещение плиток (как иконки на iOS)
- **Свайп** — переключение между комнатами
- **Вкладки** — горизонтальный скролл как в Safari

### 7.3. Адаптивность
- Телефон (<600px): 2 колонки, вертикальная погода
- Планшет (600-1023px): 3 колонки
- Десктоп (≥1024px): 4-5 колонок, сетка auto-fill
- Большой десктоп (≥1400px): до 6 колонок

## 8. Хранение данных

### 8.1. localStorage
| Ключ | Содержание |
|------|------------|
| `yandex_access_token` | Токен доступа |
| `panel_config_v3` | Конфигурация плиток и комнат |
| `weather_data` | Кэш погоды |
| `weather_config` | Координаты и город |
| `sensor_history` | История показаний датчиков (144 точки) |

### 8.2. История датчиков
- Запись каждые 10 минут
- Максимум 144 точки (24 часа)
- Мини-графики SVG с градиентной заливкой
- Автоочистка старых данных при переполнении

## 9. Развёртывание на Replit

### 9.1. Шаги
1. Создать новый Repl (Node.js)
2. Загрузить все файлы проекта
3. Выполнить в Shell:
   ```bash
   python build/install.py
   npm install
   npm start
   ```
4. Открыть веб-интерфейс Replit

### 9.2. Конфигурация Replit
- **Runtime:** Node.js
- **Port:** 3000
- **Start command:** `npm start`
- **Python:** требуется для сборки (есть в Replit по умолчанию)
